English–Persian Dictionary v3.0 for Kindle, Kobo, KOReader and StarDict apps

A free, offline English-to-Persian (Farsi) dictionary with 154,439 entries, built for e-readers. It is a revision and expansion of English-Persian Dictionary v2.4: 11,493 new entries, 7,016 core definitions rewritten, Persian spelling standardised, and 31,227 inflected forms indexed.

Frequently asked questions

How do I install an English–Persian dictionary on a Kindle?

Connect the Kindle by USB, copy English-Persian.Dictionary.v3.0-classic.mobi into documents/dictionaries, and eject. In a book, long-press a word, tap the dictionary name in the pop-up and choose English-Persian Dictionary v3.0, or set it under Settings › Language & Dictionaries › Dictionaries › English.

How do I add this dictionary to a Kobo?

Copy dicthtml-en-fa.zip into the .kobo/custom-dict folder (create it if missing), eject, then select it under Settings › Language and dictionaries. Firmware 4.24 or later is needed.

Does it work with KOReader, Onyx Boox and PocketBook?

Yes, through the StarDict build. Unzip it into koreader/data/dict/ for KOReader, which runs on Kindle, Kobo, PocketBook, Boox, reMarkable and Android, or into the dictionary folder of GoldenDict, Moon+ Reader and other StarDict apps. PocketBook's built-in dictionary uses its own format, which is not provided, so use KOReader there.

What is the difference between the classic and right-to-left Kindle builds?

Kindle dictionary pop-ups on E Ink devices lay text out left to right. The classic build, like v2.4, therefore stores each Persian definition with its words in reverse order so it displays correctly. The right-to-left build stores natural reading order with right-to-left paragraphs, for Kindle apps and firmware that handle bidirectional text. Try classic first; use the right-to-left build if sentences look reversed.

Is it free, and does it work offline?

Yes to both. It is released under the MIT licence, like the upstream project it is based on, and all look-ups happen on the device.

What is new compared with v2.4?

154,439 entries instead of 145,075. Modern vocabulary (internet, smartphone, podcast), science, medicine, business, phrasal verbs, idioms and slang were added; the 7,016 most frequent words were rewritten with the most common sense first; Persian spelling was normalised in 106,983 entries; 3,120 misspelled headwords were corrected; 2,128 duplicates were merged; and inflected forms are indexed, so looking up walked opens walk.

Were the new translations reviewed by a human editor?

No. The rewritten and new entries were written by AI language models following written lexicographic guidelines and have not been reviewed by a human Persian editor. About 107,000 specialised entries received only mechanical repairs and keep their original wording. Nothing was checked screen by screen on every e-reader generation. Please report problems or better translations.
